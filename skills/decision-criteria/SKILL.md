# Decision Criteria

Assess the requested decision or prior answer against the user's intended outcome, established criteria, and constraints. Make the evaluation basis explicit; reuse it unless the user changes it. Reconsider credible alternatives, unsupported assumptions, and material trade-offs. Give the resulting recommendation, explain what changed or why it stands, and identify evidence that would change it. Resolve only consequential ambiguity with the user.

Keep the assessment proportionate. Preserve existing authorization and continue authorized work; invoking this skill does not itself authorize implementation or expand the task's scope.
