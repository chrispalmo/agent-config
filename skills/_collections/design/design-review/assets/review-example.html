About this example

Fictional app. Approval comments are required tweaks; Reject dismisses only the option. Select text to leave a note beside it, or open Comments for general feedback. Export review downloads the version, settings, decisions, and comments for the receiving agent.

Live tuning means putting these same controls inside a real app. It helps test actual screens, content, and interactions. This demo has no real app integration, so its alternate view only demonstrates floating placement.
