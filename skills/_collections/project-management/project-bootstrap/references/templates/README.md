# Optional continuity templates

Start with the minimum missing guidance. None of these filenames or sections is mandatory. Read [the mode guide](../variants.md) before choosing structure.

| Template | Use |
| --- | --- |
| [AGENTS.md](AGENTS.md) | Name actual scope, work, decision, and evidence authorities and relevant commands. |
| [CLAUDE.md](CLAUDE.md) | One-line import of shared guidance. |
| [IMPLEMENTATION_STATUS.md](IMPLEMENTATION_STATUS.md) | Compact current-work record when Markdown is the chosen task store. |
| [VISION.md](VISION.md) | Scope needing more room than existing documentation provides. |
| [IMPLEMENTATION_PLAN.md](IMPLEMENTATION_PLAN.md) | Readable roadmap or design narrative without a duplicate executable backlog. |

Create only useful artifacts, replace placeholders with facts, and omit unused sections. Existing documents and external trackers are adequate equivalents. Templates may describe scope or point to the existing work authority.

Keep AGENTS.md and its one-line CLAUDE.md shim at the relevant directory root. Place substantial new Markdown records according to the [location guidance](../variants.md#documentation-location): prefer project-wide or area-local `docs/` as appropriate, preserve adequate existing locations, and link indexes to each record's canonical home. Do not create empty folders or move existing records solely to match the preference.

The optional ideas template belongs to status-ledger and is used only when the user asks to park an idea. Assess continuity through project-audit's evidence criteria rather than scoring template presence.
