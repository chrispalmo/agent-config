## Durable changes and handoff

When authorized work changes execution state, evidence, decisions, scope, risks, or the next action, update the affected canonical records. Mark completion with relevant evidence. Leave a concrete next action and unresolved blockers when work remains. Independent authorized items may advance together.

Do not create competing task stores, repeat known-complete work without reason, or refresh state for read-only exchanges without a durable change. Carry prior authorization forward and ask only for a consequential decision that remains unresolved. Parked ideas are not committed scope.
