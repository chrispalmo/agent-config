# Completion Summaries and Links

Whenever you finish work, give a concise, clear summary of what was done. Include relevant validation and any remaining work or blockers so the user can tell what is complete.

Whenever you mention a specific file or document in chat, provide a clickable Markdown link to it. Use an absolute path for local files and a direct URL for online documents; link to the relevant line or section when useful. If no usable location is available, say so briefly rather than inventing a link.
