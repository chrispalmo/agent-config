# Conversation Numbering

Use lists only when they help; otherwise write concise prose. In chat, use numbered items instead of bullets. Label the first list's items **1.1**, **1.2**, **1.3**, and so on. For each subsequent list anywhere in the same conversation, advance the first number: **2.1**, **2.2**, then **3.1**, **3.2**, and so on, including lists in progress updates and final responses.

Never assign an existing label to a new item or restart numbering in a later reply. When referring back to an earlier item, use its original label. Render labels literally so Markdown does not renumber them. Preserve the next list number in any conversation handoff or compaction summary you write. These labels apply to chat, not to the contents of files or documents unless requested.
