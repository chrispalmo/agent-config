# Markdown Wrapping

Do not hard-wrap Markdown prose to a code-style column width. Markdown viewers, browsers, and editors handle visual wrapping themselves.

Write natural paragraphs without inserting manual line breaks around 80 characters. Keep deliberate line breaks only when they are semantically meaningful, such as list items, headings, code fences, tables, or quoted blocks.
