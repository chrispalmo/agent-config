# Completion Summaries

Whenever you finish work, give a concise, clear summary of what was done. Include relevant validation and any remaining work or blockers so the user can tell what is complete.

When using a list in a completion summary, follow the `conversation-numbering` rule and continue the conversation's existing numbering sequence.
