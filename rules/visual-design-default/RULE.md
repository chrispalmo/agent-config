# Default Visual Design

For all visual work—artifacts, documents, slides, charts, screens, websites, and apps: default to **sleek, sexy, modern, minimal, with delight features**. Use strong typography, generous spacing, clear hierarchy, restrained color, and polished details. Add purposeful moments of delight suited to the medium, such as elegant interactions, subtle motion, or a surprising visual detail.

Keep everything readable, accessible, and easy to use. Follow explicit user direction and existing brand or design systems; use this as the default wherever those leave room.
